# sovetnikOS

**sovetnikOS** — экспериментальная учебная операционная система для компьютеров x86 (32-bit), написанная на C и NASM. Проект предназначен для изучения устройства ядра, загрузки, прерываний, памяти, драйверов и простого графического интерфейса.

> Проект находится в разработке. Это не замена Linux или Windows. Запускайте и проверяйте систему в виртуальной машине, например QEMU.

## Возможности

- Загрузка через GRUB и Multiboot.
- Ядро на C и низкоуровневый код NASM.
- GDT и IDT, обработка IRQ, PIC и PIT.
- Базовая диагностика CPU-исключений с остановкой ядра при фатальной ошибке.
- VGA text mode и framebuffer с отрисовкой текста и графических примитивов.
- Графическая оболочка с окнами и указателем мыши.
- Обработка ввода с PS/2-клавиатуры, включая специальные клавиши.
- Терминал с командами и редактированием вводимой строки.
- RAM-файловая система и загрузка начальных файлов из `initrd.tar`.
- Базовый ATA PIO-драйвер для чтения и записи секторов.
- Сборка загрузочного ISO в Linux.

Фактический набор возможностей зависит от текущей версии исходников. Некоторые функции остаются экспериментальными.

## Содержание репозитория

| Каталог / файл | Назначение |
|---|---|
| `boot/` | загрузочный код, загрузка GDT и заглушки прерываний |
| `kernel/` | ядро, обработчики исключений, память, терминал и VGA |
| `drivers/` | драйверы устройств, включая ATA и мышь |
| `fs/` | RAMFS и разбор архива TAR |
| `gui/` | графическая оболочка |
| `include/` | заголовочные файлы |
| `initrd/` | файлы, включаемые в начальный RAM-диск |
| `Makefile` | правила сборки |
| `linker.ld` | сценарий компоновки ядра |
| `grub.cfg` | конфигурация загрузчика GRUB |

## Требования

Для сборки в Ubuntu, Debian или Linux Mint установите инструменты:

```bash
sudo apt update
sudo apt install build-essential gcc-multilib nasm binutils make \
  grub-pc-bin grub-common xorriso qemu-system-x86
```

Для создания ISO могут потребоваться дополнительные пакеты GRUB в зависимости от дистрибутива и установленной архитектуры.

## Получение исходников

```bash
git clone https://github.com/demenkovmaks42-cloud/SovetnikOS.git
cd SovetnikOS
```

## Сборка

```bash
make
```

Если сборка завершилась успешно, Makefile должен создать ядро и загрузочный ISO в каталоге `build/`.

Для чистой пересборки:

```bash
make clean
make
```

Если сборка завершается ошибкой, сохраните полный вывод терминала: он поможет определить, на каком этапе возникла проблема.

## Запуск в QEMU

Обычно используется:

```bash
make run
```

Если в Makefile нет соответствующей цели, после сборки можно попробовать запуск вручную (путь к ISO должен совпадать с результатом вашей сборки):

```bash
qemu-system-i386 -cdrom build/sovetnikOS.iso \
  -drive file=disk.img,format=raw,if=ide -vga std
```

Чтобы проверить систему без подключённого ATA-диска, используйте цель `make run-nodisk`, если она определена в Makefile.

**Рекомендация:** сначала запускайте ОС в QEMU, а не на основном компьютере. Сохраняйте резервные копии образов дисков.

## Терминал

Введите:

```text
help
```

Чтобы узнать доступные команды, используйте справку самой запущенной версии ОС. Набор команд может меняться по мере разработки.

В графическом терминале поддерживаются редактирование строки и навигация по истории команд, если соответствующая реализация присутствует в вашей версии исходников.

## Ограничения

- Это учебная ОС для x86 в 32-битном режиме, а не полноценная универсальная система.
- Поддержка оборудования ограничена реализованными драйверами и эмуляцией QEMU.
- RAM-файловая система хранит данные в памяти; без отдельной файловой системы на диске данные могут теряться после перезагрузки.
- ATA PIO-драйвер сам по себе не означает наличия полноценной файловой системы на ATA-диске.
- Графика, ввод и работа с устройствами могут зависеть от видеорежима и настроек виртуальной машины.
- Не все функции обязательно проверены на физическом оборудовании.
